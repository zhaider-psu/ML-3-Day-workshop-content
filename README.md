## 🚀 Overview

Welcome to the 3-Day Machine Learning Workshop designed specifically for undergraduate students at Prince Sultan University. This hands-on course takes you from the mathematical foundations of ML to building Neural Networks, using interactive visualizations and practical Python examples (scikit-learn).

## 📅 Workshop Schedule

### **Day 1: Foundations of Statistical ML**
Building the mathematical toolkit and understanding simple predictive models.
- **Module 0:** Math Refresher (Linear Algebra, Geometry, Calculus)
- **Module 1:** Introduction to ML (Supervised vs. Unsupervised Learning)
- **Module 2:** Linear Regression (Predicting continuous values)
- **Module 3:** k-Nearest Neighbors (KNN)
- **Module 4:** Linear Discriminant Analysis (LDA)

### **Day 2: Classification & Model Health**
Moving to advanced classification and understanding how to evaluate and improve models.
- **Module 5:** Logistic Regression (Probabilistic classification)
- **Module 6:** Support Vector Machines (SVM & Kernels)
- **Module 7:** Overfitting (The Bias-Variance Tradeoff)
- **Module 8:** Evaluation Metrics (Precision, Recall, Confusion Matrices)

### **Day 3: Unsupervised & Deep Learning**
Discovering hidden patterns in data and introduction to Neural Networks.
- **Module 9:** Dimensionality Reduction (PCA)
- **Module 10:** Clustering (K-Means)
- **Module 11:** Neural Networks (Multi-Layer Perceptrons & Backpropagation)

## 💻 How to Start

1.  **Open the Dashboard:**
    Simply open `overview.html` in your web browser (Chrome, Firefox, Edge, etc.).

2.  **Navigate:**
    Use the interactive dashboard to jump between days and modules. Each module contains:
    - **Theory:** Core concepts explained simply.
    - **Interactive Demos:** Play with parameters to see ML in action.
    - **Code:** Python code snippets using `scikit-learn`.

## 🛠️ Requirements

- **Web Browser:** A modern web browser to view the interactive course materials.

### ⚡ Quick Start: VS Code + Google Colab (Recommended)
To avoid extensive local installations and start coding immediately:

1.  **Install VS Code:** Download and install [Visual Studio Code](https://code.visualstudio.com/).
2.  **Install Extensions:**
    -   Open VS Code and go to the Extensions view (`Ctrl+Shift+X`).
    -   Search for **"Google Colab"** (or **"Jupyter"**) and install it.
3.  **Run Code in the Cloud:**
    -   You can copy the Python code snippets from the workshop directly into [Google Colab](https://colab.research.google.com/).
    -   *Alternatively:* Use the VS Code extension to connect to a Colab runtime or manage your notebooks easily.

### 🐍 Local Python Setup (Optional)
If you prefer running code on your own machine, you will need:
-   Python 3.x
-   scikit-learn
-   numpy
-   matplotlib
